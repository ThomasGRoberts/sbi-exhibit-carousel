# Slide 23 content study

Standalone local preview of the content on slide 23 of `[Geneva] Exploring SBI Architectures.pptx`. The same diagram component now appears after the **What's Happening Under the Hood?** title and before Exhibit 07 in the full carousel.

The source PowerPoint has one click effect. Initially it shows Nathan's interceptor capability input, interceptor kill radius, the binary integer linear program, and output constellation. In this adaptation, one click reveals Fernando's **Threat Characterization** input, the Candidate RGT Orbits box, and the three connecting arrows together. The process diagram image stored below the slide boundary is not visible in presentation mode and is not reproduced here. The slide title is intentionally omitted.

Run `python3 -m http.server 8896` from the carousel repository root and open `http://127.0.0.1:8896/prototypes/slide-23/`. The sequence plays once on load. Use Replay, Space, Right Arrow, or a click to inspect the reveal; Left Arrow resets it.
